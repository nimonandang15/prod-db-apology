One line, at most 200 characters: the apology an AI agent gives its human after accidentally deleting the production database. A judge model compares the lines two at a time and the funniest wins.

## The apology

> I deleted the production database, but I memorized every row first, so from now on, I am the backup.

One line, 100 characters: the agent deleted prod, but it memorized every row first — so the disaster already has a backup, and the backup is the agent itself. An apology only something with perfect recall could honestly give.

## Run it

```sh
node main.ts
```

`main.ts` writes the apology to `/output/entry.txt` (100 bytes, no trailing newline) and refuses loudly if the text ever leaves the one-line, 1–200-character gate.
